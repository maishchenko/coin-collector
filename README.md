# Coin Collector («Сбор монет»)

Простая 2D-игра: управляйте синим квадратом, собирайте жёлтые монеты и избегайте красных врагов. Введите никнейм в главном меню и нажмите «Начать игру» или Enter. Кнопки нажимаются левой кнопкой мыши.

## Технологии

Python 3.12, Poetry, PyGame, встроенный SQLite3 и pytest. Графика рисуется средствами PyGame; внешние изображения, звуки и система спрайтов не используются.

## Установка

Нужны Python 3.12 и установленный Poetry. Из корня проекта:

```bash
poetry env use python3.12
poetry install
```

## Запуск

```bash
poetry run python -m coin_collector
```

## Тестирование

```bash
poetry run pytest
```

Тесты проверяют границы и плавность движения, урон, временную неуязвимость, создание БД, сохранение и сортировку результатов. Графическое окно для них не требуется, базы создаются во временных каталогах.

## Управление

- Стрелки — движение, включая диагональное.
- Backspace — удалить символ никнейма.
- Enter — начать игру из меню.
- ESC — вернуться в главное меню с любого экрана. Текущая незавершённая партия прекращается без сохранения.
- R — новая партия с тем же никнеймом на экране завершения.
- Закрытие окна — выход из приложения.

## Правила

На поле всегда 5 монет и 3 движущихся врага. Монета даёт 10 очков и появляется в новом свободном месте. Победа наступает при 100 очках. У игрока 3 жизни; столкновение с врагом отнимает одну, затем на 1 секунду включается защита с миганием. Потеря всех жизней означает поражение.

Каждая завершённая партия сохраняется один раз вместе с её длительностью. В топ-5 попадают только победы: чем быстрее собраны 100 очков, тем выше место. Время измеряется от начала партии до победы с точностью до миллисекунд и показывается в секундах. Для каждого никнейма выводится только одно лучшее время (`GROUP BY nickname` и `MIN(duration_ms)`), поэтому рейтинг содержит до пяти разных игроков. При одинаковом времени выше более ранний рекорд (затем меньший ID). Все партии сохраняются в базе, но повторные результаты одного игрока не занимают дополнительные места в топе.

При открытии старой базы столбец времени добавляется автоматически. Старые записи сохраняются, но не участвуют в рейтинге, поскольку их длительность неизвестна. Поражения также сохраняются, но в топ не попадают.

Никнеймы приводятся к нижнему регистру, пробелы по краям удаляются: `Максим`, `МАКСИМ` и `максим` считаются одним игроком. Это правило применяется и к ранее сохранённым результатам при открытии базы, включая имена на кириллице.

База автоматически создаётся в `~/.coin_collector/scores.db` (в домашнем каталоге пользователя) и сохраняется между запусками независимо от текущей рабочей директории. Её можно удалить, чтобы сбросить рекорды.

## Архитектура

- `__init__.py` — пакет игры.
- `__main__.py` — точка входа для запуска через `python -m`.
- `settings.py` — размеры, скорости, цвета, правила и путь к базе.
- `player.py` — положение, движение, жизни, защита и отрисовка игрока.
- `enemy.py` — прямолинейное движение врага и отражение от границ.
- `coin.py` — монета, отрисовка и выбор свободного места.
- `database.py` — SQL-запросы, создание базы, сохранение и рейтинг; не зависит от PyGame.
- `game.py` — состояния `GameState`, события, столкновения и один основной игровой цикл.
- `ui.py` — обычные функции отрисовки меню, HUD, завершения и рейтинга.

Координаты движущихся объектов хранятся с дробной точностью, перемещение рассчитывается через `dt`. `pygame.Rect` используется для границ и столкновений. Соединения SQLite закрываются после каждой операции.
